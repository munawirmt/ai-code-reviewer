# AI-Powered Code Reviewer

An interactive web application built with **Streamlit** and **Groq API** that acts as an intelligent code review assistant. It analyzes your code for bugs, performance optimizations, security vulnerabilities, and provides corrected refactored code.

👉 **Live Demo:** [Check out the Live App here!](https://ai-code-reviewer-4inzist4u4luuzt5brfoqc.streamlit.app/)
---

##  Features
* **Bug & Error Detection:** Identifies syntax and logical errors in your code.
* **Performance Optimization:** Suggests ways to make your code faster and more efficient.
* **Security Checks:** Highlights security vulnerabilities (e.g., hardcoded secrets, unsafe practices).
* **Refactored Code:** Provides clean, corrected code ready for production.

---

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (for the UI)
* **Groq API** (powered by fast LLM models)
